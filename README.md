# Bicycle Rental App (client)

## Описание

Клиентская часть приложения аренды велосипедов.

## Стек

- React --> библиотека для создания UI
- Vite --> сборщик
- Tailwind --> CSS-фреймворк

## Запуск

### Локально

```bash
npm install
npm run dev
```

Приложение поднимется на `http://localhost:5173`.
